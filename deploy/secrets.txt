# The settings that are secrets, read through the secrets slot (SECRETS in .env; `env` is the one backend).
# One per line: name, how scripts/settings.sh makes it when it is missing, and what it is for.
#   token:N        N random bytes, URL-safe text          provided   you give it (empty means not used)
#   key:PREFIX:N   PREFIX plus N random bytes as hex
POSTGRES_PASSWORD           token:24        Postgres superuser
GATEWAY_DB_PASSWORD         token:24        the model gateway's login to its own database (gateway: its config and its log of calls)
GATEWAY_METER_PASSWORD      token:24        the read-only login to the gateway's log of calls (gateway_meter): the meter
GATEWAY_ADMIN_PASSWORD      token:24        the gateway's admin account (its dashboard and API, S-34)
GATEWAY_KEY_SECRET          token:32        derives each caller's virtual key (scripts/gateway.py caller_key)
OPENROUTER_API_KEY          provided        the owner's OpenRouter key (capped by the owner); the gateway reads it, nothing else
STORE_EMBED_KEY             key:sk-bf-:20   the store's key at the gateway for embeddings (local models only)
KK_AUTHENTICATOR_PASSWORD   token:24        the Knowledge Kernel's one login for its services; the UI reads the kernel's read model through it (S-154)
MCP_ROUTER_DB_PASSWORD      token:24        the MCP router's login to the kernel's database (mcp_router, role env_router: lists and calls tools, records decisions; S-205)
MCP_CONNECTOR_DB_PASSWORD   token:24        the MCP connectors' login (mcp_connector, role env_connector: registers servers, applies calls; S-205)
MCP_DESKTOP_DB_PASSWORD     token:24        the desktop server's login (mcp_desktop, role env_desktop: the conversation's signals and feed; S-206)
MCP_CHANNEL_DB_PASSWORD     token:24        the channel's login (mcp_channel, role env_agent: its own queues, acting through the gates; S-220)
KK_JWT_SECRET               token:32        signs the kernel's tokens for its HTTP MCP (kk token); not used by the stdio profile
