# The settings that are secrets, read through the secrets slot (SECRETS in .env; `env` is the one backend).
# One per line: name, how scripts/settings.sh makes it when it is missing, and what it is for.
#   token:N        N random bytes, URL-safe text          provided   you give it (empty means not used)
#   key:PREFIX:N   PREFIX plus N random bytes as hex
POSTGRES_PASSWORD           token:24        Postgres superuser
WORKBENCH_AUTHENTICATOR_PASSWORD token:24   PostgREST's login to the workbench database (wb_authenticator)
WORKBENCH_JWT_SECRET        token:48        signs Workbench sign-in tokens; PostgREST and the server verify them
WORKBENCH_SERVER_PASSWORD   token:24        the Workbench server's login to its database (wb_server)
WORKBENCH_READER_PASSWORD   token:24        the read-only login for views over the store, e.g. the SPARQL endpoint (wb_reader)
