# Substrate v0.1.0-preview.1 (draft)

**A preview.** Substrate is in the middle of a re-cut (`docs/plan.md`, "The re-cut"; `docs/parts.md`, "Order"). This
release lets you install the stack, sign in to the desktop and try the assistant, the MCP router and the gateway. Its
parts, names and settings will change before 0.1.0, and no upgrade path from this preview is promised.

## What it is

The default distribution of two products: **Morphogen**, the kit (map, research, catalog and optimise, on Backstage
files, no database), and the **Knowledge Kernel** (Postgres made into a kernel: knowledge with provenance, review,
logins and row-level security, a module contract, a desktop in the browser). Substrate adds its optional parts onto
a kernel instance (the live environment and its gates, the channel into a harness, the MCP router, the assistant's
view), a configured harness (Claude Code first), a model gateway and local models, and the stack that runs them.

## What works

Checked on a fresh clone on 2026-11-27 (Ubuntu 24.04, rootless Podman 4.9.3, Docker Compose v5.8.0 as its provider),
beside another stack on the same machine: `scripts/bootstrap.sh`, `scripts/up.sh` and `scripts/check.sh` pass, and
`scripts/test.sh` passes every suite (catalog 9, environment 41, gateway 15, kernel 27, UI 36, release 10, the
router's Go tests).

- The stack from published images (or built here when they do not pull), everything on 127.0.0.1.
- The desktop at http://127.0.0.1:8080/: the kernel's shell with search, review, change sets, the graph, the view
  modules and three framed apps (the gateway's dashboard, the map pages, the MCP router's page), each on an origin of
  its own.
- Sign-ins: `scripts/kernel.sh person NAME` for a person, `scripts/kernel.sh login NAME` for an agent (its own login;
  the password is kept under `.state/`, never printed).
- The MCP router: one endpoint for agents in front of the kernel's and the desktop's tools; read-only tools run at
  once, tools that write wait for a person on the router's page; every call recorded.
- The assistant (`scripts/assistant.sh`): a Claude Code session you talk to in the desktop's Assistant window.
- The model gateway: a key per caller, the providers each may reach, every call logged without its content.
- Morphogen's plugin in Claude Code, reading Substrate's own catalog.

## Changed in this release (S-222)

- Images are pinned: compose, `scripts/lib.sh` and `.env.example` default to this release and its kernel release
  instead of `main`; `scripts/tests/test_release.py` keeps them equal to `VERSION`. A kernel image that does not pull
  is built from the kernel's release tag. The images workflow already published `v*` tags.
- A second copy on one machine, or one whose ports are taken: the desktop's framed-app ports
  (`DESKTOP_GATEWAY_PORT`, `DESKTOP_MAPS_PORT`, `DESKTOP_ROUTER_PORT`), the compose project (`COMPOSE_PROJECT_NAME`),
  the tools container (`TOOLS_CONTAINER`) and the kernel's artifact volume (`KERNEL_ARTIFACTS_VOLUME`) are settings.
  `scripts/tools.sh` no longer replaces another checkout's tools container.
- A first `scripts/up.sh` no longer fails while the gateway is still making its tables.
- `scripts/bootstrap.sh` checks for curl, which `scripts/check.sh` uses.
- The README: requirements, what works in the preview and what is moving.

## Known limits

- Tested on one Linux machine with rootless Podman. Docker (`CONTAINER_ENGINE=docker`), macOS and Windows are untested.
- Local only: no HTTPS, no multi-user setup; everything binds to 127.0.0.1.
- The local models need an NVIDIA GPU's driver libraries and GGUF files you download yourself (their licences are
  theirs; LFM3's is Liquid AI's LFM Open License v1.0).
- The assistant, the agents' MCP server and Morphogen's plugin need Claude Code; the plugin also needs uv.
- `ui/` (the old store pages on :8100) and the kernel's `substrate` MCP profile are on their way out.
- A port already in use stops `scripts/up.sh` with the engine's "address already in use"; change that port's setting.

## What's next

The re-cut's step 2 (under way): the environment as a kernel module whose gates use the kernel's review lane, the
channel and the router as MCP servers on it, the assistant's view installed into the kernel's desktop. Then the
default distribution (the compose file installs the kernel's core and Substrate's modules), then the test of the bet:
one implementation project on a demo small business, end to end, under the kernel's gates.
